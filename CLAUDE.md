## Project

Marketing/landing site for **Karga**, a Turkish mobile app (iOS + Android) for building a digital "yanlış defteri" (wrong-answer notebook) by photographing exam questions. All user-facing copy, metadata and code comments are in **Turkish**; keep new content in Turkish.

Stack: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4 (via `@tailwindcss/postcss`). No component library, no tests.

## Commands

```bash
npm run dev     # dev server on http://localhost:3000
npm run build   # production build (also type-checks)
npm run lint    # eslint (flat config, eslint-config-next)
```

There is no test suite. `convert_to_webp.py` (requires Pillow) is a one-off helper that converts the listed PNGs in `public/` to WebP; pages reference the `.webp` files.

## Architecture

### Multi-domain routing via `proxy.ts`
`proxy.ts` is the Next 16 replacement for `middleware.ts` (exported function is `proxy`, not `middleware`). It rewrites the root path `/` based on the `Host` header so one deployment serves several domains:

- `kpssyanlisdefteri.com` → `/satelit-kpss`
- `yanlisdefteri.com` → `/satelit-yanlis`
- `kesyapistir.app` → `/satelit-kesyapistir`
- anything else → `app/page.tsx` (main Karga landing)

The `satelit-*` pages are SEO "satellite" landing pages targeting specific keywords. When adding a new satellite domain, update `proxy.ts`, add the page under `app/satelit-<name>/`, and add it to `app/sitemap.ts`. The proxy matcher excludes static image extensions — new static asset types may need adding there.

### SEO is per-page and hardcoded
Each page exports its own `metadata` (title, canonical, OpenGraph, Twitter) and embeds its own JSON-LD `@graph` via a `<script type="application/ld+json">`. The root `app/layout.tsx` holds the site-wide JSON-LD (SoftwareApplication, Organization, WebSite, FAQPage), Google site verification codes, and the GA4 `gtag` scripts. The canonical base URL `https://kargasoru.netlify.app` is hardcoded across layout, pages, `sitemap.ts`, and `robots.ts` — there is no shared constant, so change it everywhere if it moves. Legacy Turkish URLs (`/gizlilik-politikasi`, `/kullanim-kosullari`) are permanently redirected to `/privacy` and `/terms` in `next.config.ts`.

### `/install` redirect + ad attribution
`app/install/page.tsx` is a client component that detects iOS/Android/desktop from the user agent, then:
- mobile: `window.location.replace()` to the App Store / Google Play URL (with a fallback UI after 1.5s)
- desktop: shows a QR code (generated by `api.qrserver.com`, allowed in `next.config.ts` `images.remotePatterns`) encoding the current URL including query string

`app/lib/trackingUtils.ts` parses UTM + custom params (`channel`, `campaign_id`, `ad_id`, `creative_id`), fires a GA4 `install_redirect` event (organic traffic tagged `utm_source=direct`), and decorates store URLs: Google Play gets UTM params in `referrer`, App Store gets `ct=<source>_<campaign>&pt=karga`. `/install` metadata lives in `app/install/layout.tsx` because the page is a client component. `window.gtag` is typed in `app/types/gtag.d.ts`.

App store URLs (App Store id `6770515165`, Play package `com.ergunenes.sorucek`) are duplicated across pages and `trackingUtils.ts`.

### Karga Kodu (`/k`)
`/k/[code]` shares are fetched server-side from the `getShare` Cloud Function (`soru-cek` repo, `functions/src/share/index.ts`); images load directly in the browser from `getShareImage`. Because the fetch comes from Netlify, `fetchShare` forwards the visitor IP in `x-karga-client-ip`, authenticated by the `SHARE_PROXY_KEY` env var (Netlify, Functions scope), which must match the Firebase secret of the same name. Without it the function's per-IP rate limit applies to Netlify's IP for all visitors.

### Styling
Design tokens are defined with Tailwind v4 `@theme inline` in `app/globals.css` (`primary`, `secondary`, `background`, `surface`, `text-main`, `text-secondary`, etc.) — use these token classes (e.g. `bg-primary`, `text-text-main`) rather than raw colors. There is no `tailwind.config.*` file. Fonts are Geist via `next/font`.
